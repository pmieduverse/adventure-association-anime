# ADVENTURE ASSOCIATION (Anime Edition)

**Know Your Potential. Earn Your Rank. Begin Your Adventure.**

Anime-style Adventurer Registration, Assessment & Ranking portal.

## Features

- **20+ Origin clans** — Elf, Vampire, Angel, Oni, Kitsune, Phoenix, Titan, Voidborn, Mech-Blood, Fairy, Reaper + originals
- **40+ powers** + **custom power registration** (system classifies affinity / rarity / difficulty)
- **Chat + Voice assessment** — describe yourself; AI assigns attributes
- **20 anime avatars** for profile
- **Rank-wise ID cards** (E → EX different glow & license titles)
- Power synergy, awakened ability, missions, dashboard, registry, admin
- **localStorage** — all registered adventurers saved on device

## How to Run

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

Or open `index.html` in a modern browser.

## Structure

```
index.html
css/styles.css
js/data.js
js/app.js
```

Pure HTML / CSS / Vanilla JS. No backend required.
