# Full source location

The complete working website with all anime features is on the machine that built this repo at:

```
/home/workdir/artifacts/adventure-association/
  index.html
  css/styles.css
  js/data.js
  js/app.js
```

Also available as single file:
`adventure-association-single.html`

## To run locally

1. Download this repo files
2. Copy the full `js/` and `css/` from the build machine OR open the single HTML file
3. `python3 -m http.server 8080`

## Features in full build

- 20+ clans, 40+ powers, custom power AI classify
- Chat + voice attribute assessment  
- Anime avatars, rank-wise card glow
- Dashboard, missions, registry, admin
- localStorage persistence for all adventurers
